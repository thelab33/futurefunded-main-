# FutureFunded Sister Demo Runbook

This is the simple operating flow for running the Connect ATX Elite demo campaign.

## 1. Log in

Open:

    /platform/login

Use the operator email/password Angel gives you.

After login, open:

    /platform/dashboard

## 2. Review campaign setup records

On the dashboard, find:

    Campaign setup records

This table shows saved setup versions. Each row has:

- readiness score
- campaign name
- current status
- workflow dropdown
- updated time
- open/review link

## 3. Use the workflow status

Use the workflow dropdown to keep setup records organized.

| Status | Meaning |
|---|---|
| Draft | Not ready yet |
| Review needed | Needs Angel/operator review |
| Launch-ready | Ready to share |
| Launched | Actively being used |
| Archived | Old version, kept for history |

After changing the dropdown, click **Update**.

## 4. Open and edit a setup

Click **Open** on any setup record.

This opens the saved onboarding setup. You can review the details, adjust campaign information, then save onboarding details again.

Saving creates a new version.

## 5. Confirm donations

On the dashboard, use:

    Recent donations

This shows confirmed ledger records from payment activity.

## 6. Add offline support

Use:

    Offline support

This is for cash, checks, or external support.

Fill in:

- amount
- donor name
- donor email if available
- internal note

Then click **Add offline donation**.

## 7. Review sponsor fulfillment

Use:

    Sponsor orders pending review

Sponsor orders appear here after sponsor payments or package activity.

Before public recognition, confirm:

- business name
- package/tier
- logo or recognition copy
- sponsor contact information
- any special notes

## 8. Export records

Click:

    Export CSV

Use this when you need records for coaches, family admins, school staff, sponsors, or bookkeeping.

## 9. Daily operating rhythm

For active campaign days:

1. Open dashboard
2. Check latest setup status
3. Review new donations
4. Add offline gifts
5. Check sponsor follow-up
6. Export CSV if needed
7. Mark setup/campaign status honestly

## 10. What to ask Angel for

Ask Angel if:

- checkout does not open
- a payment does not show up
- a sponsor needs public placement
- a setup should be archived
- the campaign is ready to move from Launch-ready to Launched
