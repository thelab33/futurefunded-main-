# FutureFunded Founder Demo Script

## 30-second opener

FutureFunded is a premium fundraising platform for youth teams, schools, nonprofits, and clubs. It gives each organization a polished public campaign page, donor-safe checkout flow, sponsor packages, and an operator dashboard that keeps donations, sponsors, offline contributions, and exports organized.

## Demo flow

### 1. Platform homepage

Open:
/platform/

Say:
This is the platform-facing page. It explains FutureFunded as fundraising infrastructure, not just a donation button. The goal is to sell trust to organizers, schools, clubs, and sponsors.

Point out:

- premium product positioning
- campaign demo CTA
- onboarding CTA
- sponsor-ready language

### 2. Public campaign page

Open:
/c/connect-atx-elite

Say:
This is the flagship public surface. It is built to help a donor understand the cause, trust the campaign, pick an amount, and give from mobile.

Point out:

- clear campaign ask
- progress meter
- suggested donations
- secure checkout path
- sponsor packages
- share/QR tools
- FAQ and use-of-funds trust

### 3. Checkout and sponsor modals

Click:

- Donate
- Sponsor

Say:
The MVP keeps giving simple. Donors get a focused checkout path. Sponsors get a structured package flow, so local businesses know exactly what they are supporting.

### 4. Operator login

Open:
/platform/login

Say:
Organizers get a protected backend, not a spreadsheet nightmare.

### 5. Dashboard

Open:
/platform/dashboard?operator_token=<demo-token>

Say:
This is the operator command center. It shows ledger health, donations, sponsors, offline entries, export tools, and provider events.

Point out:

- donation ledger
- sponsor review queue
- offline donation entry
- CSV export
- payment audit trail

### 6. Onboarding

Open:
/platform/onboarding

Say:
FutureFunded is designed to be repeatable. A team, school, or nonprofit can enter the basics and move toward a launch-ready campaign without needing a custom web build.

## Close

FutureFunded turns fundraising into a trustworthy campaign system: public donor page, sponsor packaging, payments, ledger, and operator workflow in one product.
