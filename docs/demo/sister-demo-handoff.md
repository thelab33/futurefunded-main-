# FutureFunded Sister Demo Handoff

## Goal

Show the product without explaining the engineering.

The demo should prove four things:

1. A donor can give.
2. A sponsor can understand the packages.
3. The organizer can review campaign readiness.
4. The platform feels trustworthy enough to share.

## Demo pages

- Platform: https://getfuturefunded.com/platform/
- Campaign: https://getfuturefunded.com/c/connect-atx-elite
- Onboarding: https://getfuturefunded.com/platform/onboarding
- Login: https://getfuturefunded.com/platform/login
- Dashboard: use the private operator link only.

## Demo talk track

### 1. Platform page

Say:

> This is FutureFunded — one clean place for a team, school, club, or nonprofit to launch a premium fundraising campaign.

Point out:

- Professional homepage
- Sponsor-safe language
- Mobile-first design
- Public campaign preview

### 2. Campaign page

Say:

> This is the page families, donors, and local sponsors would actually share.

Click:

- Give securely
- Sponsor options
- Share campaign

Point out:

- Clear progress
- Trust signals
- Sponsor recognition
- Static impact cards
- Mobile-ready donation flow

### 3. Onboarding

Say:

> This is the private setup workspace. It keeps the public campaign clean while the organizer sets the campaign basics, brand colors, sponsor packages, and launch readiness.

Click:

- Brand Kit presets
- Preview campaign
- Save launch setup

### 4. Dashboard

Say:

> This is the operator command center. The organizer can check readiness, donation activity, sponsors, and campaign operations.

Point out:

- Launch readiness
- Ledger/export direction
- Sponsor review
- Follow-up workflow

## Best closing line

> The platform is built around the real flow: setup, share, give, sponsor, and manage the campaign from one place.
