# Operator Dashboard Checklist

## Before showing dashboard

- Use private operator link only.
- Do not paste the real token in public notes.
- Confirm dashboard opens with token.
- Confirm locked dashboard returns protected status without token.

## Demo checklist

Show:

- Launch readiness
- Donation activity
- Sponsor review
- Follow-up workflow
- Export/ledger direction

Say:

> The dashboard is where the organizer manages the campaign after the public page is live.
